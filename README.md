# custom-dev-ai-skills

The City of Asheville's central, public source of truth for **AI coding-agent skills**. City
repositories install skills from here at a pinned release tag, so every repo gets the same reviewed
content and CI can detect drift. The skills work in **Claude Code**, **Gemini CLI / Antigravity**
and **GitHub Copilot** (VS Code and the github.com coding agent).

This is **not an npm package**. Skills are installed straight from git tags with the
[`skills`](https://github.com/vercel-labs/skills) CLI.

## Quick start (consuming repo)

```bash
export DISABLE_TELEMETRY=1
npx skills@1.7.6 add coa-internal/custom-dev-ai-skills#v1.0.0 \
  --skill git-pr-description \
  -a claude-code gemini-cli antigravity github-copilot --copy -y
git add skills-lock.json .claude/skills .agents/skills
```

> The git ref goes after `#`. In this CLI `owner/repo@name` selects a *skill*, not a version.

Then add the CI check. See **[docs/CONSUMING.md](docs/CONSUMING.md)** for upgrades, CI and the
`local-` rule for repo-specific skills.

## Contributing

Anyone at the City can propose a skill or a change. The dev team reviews and merges. Start with
[CONTRIBUTING.md](CONTRIBUTING.md), [docs/AUTHORING.md](docs/AUTHORING.md) and the annotated
[`skills/skill-template/`](skills/skill-template/SKILL.md).

```bash
npm ci
npm run lint            # frontmatter + structure rules
npm run catalog         # regenerate the table above
npm run smoke           # install every skill for each agent target
```

## Records and AI use

Skills in this repo, and copies of them in other repos, may be public records under
N.C.G.S. §132. Never put PII, credentials, internal hostnames or privileged content in a skill.
Parts of this repo were drafted with AI assistance (Claude Code) and reviewed by City staff.
Skill output is AI-generated and must be verified by the person using it.

Design plans are in [docs/plans/](docs/plans/), starting with the original
[repo buildout plan](docs/plans/skills-repo-buildout.md). To report a security problem, see
[SECURITY.md](SECURITY.md).
