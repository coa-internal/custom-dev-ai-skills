# Architecture decision records

Decisions about City-wide development standards and about this repository, with their reasoning.
People read these; AI tools rarely need to. The rules themselves live in the `dev-standards` skill
([`skills/dev-standards/references/`](../../skills/dev-standards/references/)), where consuming
repositories install them at a pinned version.

ADRs drafted with AI start as **Proposed**. Only the dev team marks one **Accepted**. An accepted
ADR is changed by pull request; a reversal gets a new ADR that supersedes the old one.
